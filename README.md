# C++ Battle Game

A console-based battle game written in C++ using object-oriented programming.

## Overview
This project simulates a simple battle between characters. It focuses on representing game entities as classes and managing combat-related behavior.

## Project Structure
- `character.hpp` / `character.cpp` — Character attributes and actions
- `main.cpp` — Main program and game flow
- `Eng_nwachukwu_HA_06.cpp` — Additional program file
- `CMakeLists.txt` — CMake build configuration

## Features
- Character-based gameplay
- Battle logic
- Object-oriented design
- Console-based interaction

## Build and Run

```bash
cmake -S . -B build
cmake --build build
```

Run the generated executable from the `build` directory.

## Topics Demonstrated
- C++ classes and objects
- Header and source file separation
- Encapsulation
- Game logic
